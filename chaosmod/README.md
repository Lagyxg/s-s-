# Вселенский пиздец (Forge 1.20.1)

## Сборка
1. Нужна Java 17 и интернет.
2. Положи в папку Gradle wrapper (`gradle wrapper --gradle-version 8.1.1`) или открой проект в IntelliJ IDEA, она подтянет всё сама.
3. `./gradlew build` -> jar лежит в `build/libs/`.
4. Тест в игре: `./gradlew runClient`.

## Настройка
Шанс срабатывания: константа `CHANCE` в `ChaosEvents.java`.
Новый эффект: добавь лямбду в список `EFFECTS`.

## Бунт предметов (RebelItemsEvents.java)
- Меч иногда отказывается бить, чем он изношеннее, тем чаще.
- Кирка орёт в чат, особенно если ломаешь блок, который не для неё.
- Яблоко иногда убегает из руки вместо того, чтобы быть съеденным.
- Съеденная еда может высказать претензии.
Все шансы лежат константами в начале файла.
